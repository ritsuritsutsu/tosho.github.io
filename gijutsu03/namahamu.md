# 生ハムのおいしい食べ方

生ハムは塩気と旨味、ほのかな甘みが魅力。ちょっとした工夫で、おつまみにも主役のおかずにもなります。

## 1. まずは基本のコツ

- **食べる15〜30分前に冷蔵庫から出す**: 冷たいままだと脂が固く、香りも立ちません。常温に近づけると脂がとろけて旨味が広がります。
- **重ねすぎない**: 1枚ずつふんわり広げて盛ると、口どけが良くなります。
- **加熱しない(基本は)**: 生ハムはそのままが一番おいしい食べ方。加熱する場合は仕上げにのせるのがコツです。
- **ハーブやナッツで香りをプラス**: 黒こしょうやオリーブオイルを少し足すだけでも印象が変わります。

## 2. 定番の組み合わせ

### フルーツと合わせる
塩気と果物の甘さは相性抜群です。

| フルーツ | ポイント |
|---|---|
| メロン | 王道。熟したものを一口大に切って巻く |
| 柿 | 秋の定番。とろっとした甘みと好相性 |
| いちじく | 濃厚な甘さと生ハムの塩気が合う |
| 桃・梨 | 瑞々しさでさっぱりした味わいに |
| りんご・キウイ | 酸味がアクセントになる |

### チーズと合わせる
- **モッツァレラ**: 生ハムで巻いてオリーブオイルと黒こしょうをかけるだけ
- **クリームチーズ**: ハムで巻いて、はちみつを少したらす
- **カマンベール**: 一口大に切ってハムで包む
- **パルミジャーノ**: 薄く削ってのせると旨味が重なる

### 野菜と合わせる
- **ルッコラ**: 苦味とピリッとした風味が生ハムを引き立てる
- **アスパラガス**: 茹でて(焼いて)生ハムで巻く
- **トマト・ミニトマト**: カプレーゼ風に
- **アボカド**: まろやかさが加わり、満足感アップ

## 3. おすすめレシピ

### ① 生ハムとモッツァレラのカプレーゼ
1. モッツァレラとトマトを食べやすい大きさに切る
2. 皿に並べ、生ハムをふんわりのせる
3. バジル、オリーブオイル、黒こしょうをかけて完成

### ② 生ハムのサラダ(ルッコラ&パルミジャーノ)
1. ルッコラを皿に広げる
2. 生ハムをのせ、パルミジャーノを削る
3. オリーブオイル、レモン汁、塩少々で和える

### ③ 生ハムのカナッペ
1. バゲットを薄く切ってトースターで軽く焼く
2. クリームチーズを塗る
3. 生ハムをのせ、はちみつや黒こしょうで仕上げる

### ④ 生ハムと春雨(または冷やし麺)のサラダ
1. 茹でて冷やした麺や春雨を用意する
2. きゅうり、トマトなどの野菜と合わせる
3. 生ハムをのせ、オリーブオイルとレモンのドレッシングをかける

### ⑤ 生ハムのピザ(焼き上がりにのせる)
1. ピザ生地にチーズとソースをのせて焼く
2. 焼き上がり直後に生ハムをのせる
3. ルッコラを添えれば専門店風に

### ⑥ 生ハムのパスタ(仕上げにのせる)
- クリームソースや、レモン風味のオイルパスタに最後にのせる
- 余熱でハムの脂がほんのり溶けて香りが立ちます

## 4. おすすめのお酒

| お酒 | 理由 |
|---|---|
| スパークリングワイン | 泡と酸味が塩気と脂をさっぱりさせる |
| 白ワイン(辛口) | 軽めの生ハムと好相性 |
| 軽めの赤ワイン | 熟成タイプの生ハムに |
| ビール | 塩気と炭酸の組み合わせで進む |
| シェリー酒 | スペイン産ハムの定番ペアリング |

## 5. 保存と扱いのポイント

- 開封後は**早めに食べきる**のが基本です。
- 残ったら**ラップでぴったり包んで**冷蔵し、乾燥を防ぎます。
- 冷凍も可能ですが、食感はやや変わります。
- 賞味期限・保存方法は、**商品パッケージの表示に従ってください**。
- 妊娠中の方や免疫力が低下している方は、生ハムの摂取について医師などに確認すると安心です。
