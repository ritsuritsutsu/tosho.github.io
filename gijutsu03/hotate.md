# おいしいホタテ料理の作り方

ホタテは旨味と甘みが強く、火の通し方と下ごしらえで仕上がりが大きく変わります。基本のコツと、定番のレシピをまとめました。

## 1. おいしく仕上げる基本のコツ

- **水気をしっかり拭き取る**: キッチンペーパーで表面の水分を取ると、焼いたときに香ばしい焼き色がつきます。
- **常温に近づける**: 調理の10〜15分前に冷蔵庫から出すと、火の通りが均一になります。
- **加熱しすぎない**: 火を入れすぎると身が縮んで固くなります。表面に焼き色をつけ、中はほんのり半生〜しっとりが目安です。
- **冷凍の場合は低温で解凍**: 冷蔵庫でゆっくり解凍し、出てきた水分はしっかり拭き取ります。
- **強めの火で短時間**: フライパンをしっかり熱してから焼くのがポイントです。

## 2. 定番レシピ

### ① ホタテのバター醤油ソテー

**材料(2人分)**
- ホタテ貝柱(刺身用または加熱用): 8〜10個
- バター: 15g
- 醤油: 小さじ2
- 酒: 大さじ1
- サラダ油: 小さじ1
- 小麦粉(薄く): 少々
- 黒こしょう、小ねぎ: 適量

**作り方**
1. ホタテの水気をキッチンペーパーで拭き、薄く小麦粉をまぶす。
2. フライパンにサラダ油を熱し、強めの中火でホタテを並べる。
3. 片面を約1分半〜2分、動かさずに焼いて焼き色をつける。
4. 裏返してバターを加え、さらに約1分焼く。
5. 酒と醤油を回し入れ、サッとからめて火を止める。
6. 黒こしょうと小ねぎを散らして完成。

### ② ホタテのカルパッチョ

**材料(2人分)**
- 刺身用ホタテ貝柱: 6〜8個
- オリーブオイル: 大さじ1
- レモン汁: 小さじ2
- 塩: 少々
- 黒こしょう: 少々
- お好みで: ベビーリーフ、ミニトマト、ピンクペッパー

**作り方**
1. ホタテを厚さ3〜4mmの薄切りにする(横にスライス)。
2. 皿に並べ、塩を軽くふる。
3. レモン汁とオリーブオイルを回しかける。
4. 黒こしょうと、お好みの野菜やハーブを添える。

> 刺身で食べる場合は、必ず「刺身用」と表示された新鮮なものを使ってください。

### ③ ホタテのクリームパスタ

**材料(2人分)**
- パスタ: 160〜200g
- ホタテ貝柱: 6〜8個
- 玉ねぎ(薄切り): 1/4個
- 白ワインまたは酒: 大さじ2
- 生クリーム: 150ml
- 牛乳: 50ml
- 塩、こしょう: 適量
- オリーブオイル: 大さじ1
- パセリ: 適量

**作り方**
1. パスタを袋の表示どおりに茹でる(塩を入れたお湯で)。
2. ホタテは水気を拭き、強火で両面に軽く焼き色をつけて、いったん取り出す。
3. 同じフライパンで玉ねぎを炒め、白ワインを加えてアルコールを飛ばす。
4. 生クリームと牛乳を加えて軽く煮詰め、塩・こしょうで味を調える。
5. 茹でたパスタを加えてからめ、最後にホタテを戻す。
6. 皿に盛り、パセリを散らして完成。

### ④ ホタテの炊き込みご飯

**材料(3〜4人分)**
- 米: 2合
- ホタテ貝柱(缶詰または生): 100〜150g
- 醤油: 大さじ1と1/2
- みりん: 大さじ1
- 酒: 大さじ1
- 昆布(5cm角): 1枚
- しょうが(千切り): 1かけ
- 水(または缶詰の汁を含めた水分): 炊飯器の2合の目盛りまで

**作り方**
1. 米を研いで30分ほど浸水させる。
2. 炊飯器に米、調味料、昆布、しょうがを入れ、水を目盛りまで入れる。
3. ホタテをのせて普通に炊く。
4. 炊き上がったら昆布を取り出し、全体をさっくり混ぜる。
5. お好みで三つ葉や小ねぎを散らす。

### ⑤ ホタテのアヒージョ

**材料(2人分)**
- ホタテ貝柱: 8個
- マッシュルーム: 4〜5個
- にんにく(薄切り): 2片
- 赤唐辛子: 1本
- オリーブオイル: 150ml程度
- 塩: 小さじ1/3
- バゲット: 適量

**作り方**
1. 小さめのフライパンまたはスキレットにオリーブオイル、にんにく、赤唐辛子を入れ、弱火にかける。
2. にんにくの香りが立ってきたら、塩を加える。
3. ホタテとマッシュルームを入れ、弱めの中火で3〜4分ほど火を通す。
4. 熱々のうちに、バゲットをオイルにつけて食べる。

## 3. 調理方法別のポイント

| 調理法 | ポイント |
|---|---|
| ソテー | 水気を拭いて、強めの火で表面だけ焼く |
| 刺身・カルパッチョ | 刺身用を選び、薄く切ると甘みが引き立つ |
| 煮込み・クリーム系 | 先に焼き色をつけて取り出し、最後に戻す |
| 炊き込みご飯 | 昆布やしょうがで旨味と香りを補う |
| 天ぷら・フライ | 衣をつけたら高温でサッと揚げる |

## 4. 相性のよい食材・調味料

- **乳製品**: バター、生クリーム、チーズ
- **柑橘**: レモン、すだち、ゆず
- **香味野菜**: にんにく、ねぎ、しょうが、玉ねぎ
- **きのこ**: マッシュルーム、しいたけ
- **野菜**: ほうれん草、アスパラガス、ブロッコリー、じゃがいも
- **調味料**: 醤油、味噌、白ワイン、塩こうじ

## 5. 保存と扱いのポイント

- 購入後はなるべく早く使い切るのがおすすめです。
- 生のホタテは冷蔵で保存し、**商品の消費期限・保存方法の表示に従ってください**。
- 冷凍する場合は、水気を拭いてラップで包み、冷凍用保存袋に入れます。
- 加熱用のホタテは、**中心まで十分に加熱して**食べましょう。
- 貝類にアレルギーがある方は、食べないようにしてください。
